# miniasciigamemsys2package
An mini ascii game package.
# Compactibility
Compactible with the ucrt64 msys2 console.
# Installation
Install in [miniasciigamemsys2package download](https://github.com/limidadidou/miniasciigamemsys2package/releases/download/gamepackage/limigame-1.0-1-x86_64.pkg.tar.zst) and run the command: pacman -U limigame-1.0-1-x86_64.pkg.tar.zst .
# What is
Is a mini game with a character who collects coins (activate the game with the command limigame)
# Uninstallation
Run the command pacman -R limigame
